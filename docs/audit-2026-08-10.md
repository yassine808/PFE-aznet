## What was verified, and how

- **`/process` contract** (`main.py`): exactly one of `audio` / `image` /
  `text` → 422; unknown provider / bad input → 422; engine failure
  (`TranscriptionError` / `ExtractionError`) → 502 so n8n can catch it; a
  transcription under 10 chars → `short_transcription` warning, not an error.
  The image path runs the vision model once (no intermediate transcript),
  prefixes the summary `[photo] `, and always sets `flag_review=true`. Image
  input is size-capped at `MAX_IMAGE_BYTES`.
- **`logs.py` query shapes**: every list endpoint is a single query — no N+1
  anywhere. `list_logs` is one `SELECT` (logs.py:799), `stats` is two,
  `read_samples` is one windowed `SELECT` (logs.py:1540), `list_media` caps at
  200 and `get_media` returns the blob as `bytes()`. All `limit` params are
  capped (audit finding #11 holds). `insert_samples` uses `executemany`.
- **Provider registry**: `@register("groq")` / `@register("gemini")` /
  `@register("local")` populate the registry; adapters are imported at the
  bottom of `providers/__init__.py` to trigger registration. The `hf_darija`
  adapter was deleted 2026-08-08 (endpoint no longer resolves, checkpoint
  404) and nothing dangles: `config.py` keeps only a comment, `schemas.py`
  only a docstring example. Gemini carries a 4096-token cap and a
  repetition-guard, added after a 2026-08-07 runaway (222 797 chars in 129 s).
- **`useApi` cache** (`Dashboard/src/lib/api.ts`): stale-while-revalidate with
  a subscriber list so remounts repaint instantly and polls propagate; the
  hidden-tab pause (audit #10) is present at api.ts:820-834; errors are kept
  and shown, never swallowed into an empty state; a 401 dispatches
  `aznet:unauthorized` once, globally.
- **Dashboard edge cases**: routes are lazy except Overview (small); the
  org-chart drag-and-drop accents only the hovered target and the `<select>`
  is the touch/keyboard path (documented in CLAUDE.md); `VersionModal` guards
  `showModal()` against StrictMode double-invoke (report-editor.tsx:459-461);
  page-visit time flushes via `sendBeacon` on `pagehide`; `DiffView` shows a
  sign per line as well as a tint, so the change gutter is not hue-only.

## Perf hypotheses checked and dismissed

The plan carried three speculative optimizations. All three were measured
against the code and are non-problems:

1. **N+1 in `/logs`** — false. One `SELECT`, no per-row follow-ups (logs.py:799).
2. **`/service-samples` returning raw rows** — false. One windowed `SELECT`,
   `hours` capped at `24 * 30`; 2 h at a 30 s cadence is ~240 rows (logs.py:1540).
3. **Dashboard bundle** — already lazy-loaded; `motion`/Phosphor are imported
   per symbol and tree-shaken.

## Notes that are not findings

- Audit #10's "related, lower priority" note is still open: two components on
  the same `useApi` key each run their own fetch and their own interval — the
  module cache dedupes the *paint*, not the *request*. Harmless at this poll
  scale; would matter only if a key were polled by many mounts at once.
- `n8nStatus` detects a rejected API key by string-matching the 502 detail for
  "rejected" (api.ts:168-175). Brittle if the API's detail text ever changes,
  but self-contained and the only signal available through the proxy.
- `list_logs` uses `SELECT *`, so each row carries its `payload` — fine at
  limit 50 per poll, worth a column list only if a payload ever grows large.
- Post-PFE backlog untouched (see `TO-DO.md`): retention policy for the
  archive tables (`media_files`, `chat_messages`, `notifications`,
  `manager_reports`), `SMTP_USER`/`SMTP_PASS` unset, STT benchmark still
  blocked on the empty `benchmark/dataset/audio/`.
