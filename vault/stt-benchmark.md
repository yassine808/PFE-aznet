# STT Benchmark

## Status: Pending

The STT benchmark (`benchmark/run_benchmark.py`) exists as a script but **the dataset is still empty** (`benchmark/dataset/audio/` has no recordings). No providers have been formally benchmarked.

## Current Default

`stt_provider` defaults to `groq` (Whisper-large-v3) by assumption, not evidence.

## Providers to Compare

| Provider | Model | Type | Notes |
|---|---|---|---|
| `groq` | Whisper-large-v3 | Cloud API (Groq free tier) | Used in production since March 2026. Returns `avg_logprob` for confidence. 30 RPM / 14K RPD limit |
| `gemini` | Gemini 2.5 Flash native audio | Cloud API (free tier) | Useful fallback. Returns no logprob. 1,500 RPM |
| `hf-darija` | HF Inference API Darija fine-tune | Cloud API (free) | Not yet tested. Depends on which Darija model exists on HF. Only added if Groq is insufficient for Darija |

## Benchmark Script (`run_benchmark.py`)

The script:
1. Reads all audio files from `dataset/audio/`
2. Sends each to every configured provider
3. Computes WER/CER (if reference transcript exists)
4. Logs confidence, processing time, word error rate
5. Produces a comparison table

Planned sample size: 50+ audio clips covering different accents, recording qualities, and technical vocab.

## Blocking Issue

No field recordings from technicians available yet. Synthetic Darija audio generated by TTS would not reflect real-world conditions (background noise, low bitrate, accent variation).

Next step: ask technicians to record a few real voice notes specifically for the benchmark.
